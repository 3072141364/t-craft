读 `skill://traft-todos`，按 Tasks checkbox 流程走。

- `/traft-todos 记录 修一下登录页按钮`：在周报「📋 本周任务」列表加一行 `- [ ] 🟡 P1 | 修一下登录页按钮 | ⏰ 待定`（checkbox 待办，含优先级+描述）。
- `/traft-todos 完成 修登录页`：把该行 `[ ]` 改成 `[x]`（勾掉即完成，留在原列表）。
- `/traft-todos 生成 周报`：复制 `skills/obsidian/templates/weekly.md` 到本周周报（**严格遵循模板格式**），任务都记在一个列表；周结时 `[x]` 留在本周，`[>]` 的任务复制到下周周报。
## 写 todo 步骤

### 第一步：计算周报路径

先用 `bash` 计算 vault 路径和 ISO 周，得到周报路径：

```bash
vault=$(obsidian vault info=path 2>/dev/null)
iso_week=$(date +%G-W%V)
echo "$vault/weekly/周记 $iso_week.md"
```

### 第二步：读周报内容

用 `read` 工具读周报文件，找到「📋 本周任务」章节的末尾。

### 第三步：追加一行

用 `edit` 工具在「📋 本周任务」列表末尾追加一行：

```
- [ ] 🔥 P0 | 任务描述 | 👤对接人 ⏰时间 | 🔗 [[卡片]]
```

- 不改已有内容，不覆盖，只加一行。
- 优先级必填：🔥P0 / 🟡P1 / 🟢P2。
- 状态只允许 `[ ]/[x]/[/]/[-]/[>]`。

## 更新 todo 步骤

### 第一步：计算周报路径

同上，`bash` 算出周报路径。

### 第二步：读周报内容

用 `read` 工具读周报文件，找到目标 todo 行。

### 第三步：改状态

用 `edit` 工具把该行状态符号改成目标状态：

| 操作 | 旧状态 | 新状态 |
|------|--------|--------|
| 完成 | `[ ]` | `[x]` |
| 进行中 | `[ ]` | `[/]` |
| 阻塞 | `[ ]` | `[-]` |
| 延期转下周 | `[ ]` | `[>]` |

例如 `[ ]` 改为 `[x]` 表示完成，留在原列表不删除。
