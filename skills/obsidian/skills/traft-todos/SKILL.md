# traft-todos 技能

轻量临时小任务管理，用 Obsidian **Tasks 插件**的 checkbox 管理，任务行统一记录在周报。**勾掉即完成**。

**职责边界**：
- 负责：临时小任务的记录、状态勾选、周报维护与周结结转。
- 不负责：项目任务/需求进展（✨feat/🐛bugfix/🔍debug）的主体管理、跨周跟进、看板/甘特视图——归 `traft-task`。超出边界时直接转交，不硬接。

## 1. 触发条件（TRIGGER）

| 场景 | 触发信号(关键词/典型句式) | 是否触发 |
| --- | --- | --- |
| 记临时任务 | "加个todo"、"记个临时任务" | 触发 |
| 更新任务状态 | "勾掉这个task"、"todo状态"、"更新一下todo任务状态"、"这个todo做完了" | 触发 |
| 周报/周结 | "这周做过啥"、"生成周报"、"把这几个任务结转到下周"、"整理下周报"、"重新排一下" | 触发 |
| 查询 todo | "查 进行中"、"本周有哪些待办"、Tasks 查询语法 | 触发 |
| 项目任务/需求进展 | "这个需求进展如何"、"给 feat 排期"、"bugfix 状态" | 不触发，转交 `traft-task` |
| 闲聊/泛泛提问 | "随便聊聊"、"你怎么看" | 不触发，交给默认回复 |

## 2. 规则（RULES）

### 2.1 务必执行(ALWAYS DO)
1. 一行 = 一个 todo，格式固定：`- [checkbox] 优先级 | 内容 | 👤 对接人 ⏰ 时间 | 🔗 [[卡片]]`，写进周报「📋 本周任务」列表。
2. 状态只用 Tasks 符号（见 5.1 状态表），勾掉 `[x]` 即完成。
3. 周报就是一个 task 列表：不按完成/下周/阻塞分块。
4. 周结时把 `[>]` 的任务复制到下周周报（结转），`[x]` 留在本周。
5. 操作前先确认周报存在；不存在则先按模板建周报。
6. deadline 是相对时间（"周五前"）时，换算为具体日期 `YYYY-MM-DD` 写入；没有明确时间才写 `⏰ 待定`。
7. 整理/重排周报时按 状态（未完成在前，`[x]` 在后）→ 优先级（P0 > P1 > P2）排序，同级保持原顺序。

### 2.2 禁止执行(NEVER DO)
1. 不自由发挥状态符号（自定义符号/emoji 代替 checkbox），只用 5.1 状态表符号。
2. 不把项目需求进展（✨feat/🐛bugfix/🔍debug）主体记成 todo——归 `traft-task`；项目任务周内完成可在周报留一条 `[x]` 记录。
3. 不在正文重复写"已完成/未开始"，checkbox 即状态。
4. 不臆造优先级/对接人/时间：用户没给就省略字段（`优先级` 必含，其余可选）。

### 2.3 条件执行(CONDITIONAL)
- 需要的输入：周报文件（`weekly/周记 <ISO周>.md`）、任务内容与优先级。
- 缺失时：
  - 周报不存在 → 先复制 `skills/obsidian/templates/weekly.md` 建周报，再执行操作；如实告知已新建。
  - 任务内容/优先级缺失 → 向用户确认，不猜测补全。

## 3. 知识底座（CONTEXT）

- **载体**：Obsidian Tasks 插件 checkbox；周报文件 `weekly/周记 <ISO周>.md`（ISO 周命名）。
- **模板**：`skills/obsidian/templates/weekly.md`，建周报严格遵循模板格式。
- **状态速查**：`resource/Tasks状态速查表.md`（符号 `[ ]`待办 `[x]`完成 `[/]`进行中 `[-]`取消/搁置 `[>]`转发下周 `[<]`排期）。
- **优先级**：P0 紧急且重要（🔥）、P1 重要不紧急（🟡）、P2 空闲时推进（🟢）；排序时 P0 > P1 > P2。
- **分工**：`traft-task` 管项目任务/需求进展，载体 `project/…/任务.md` + task-component 视图；`traft-todos` 管临时小任务，载体周报 checkbox 行。
- **查询**：Tasks 插件 `filter by function task.tags.includes('#todo')` 汇总所有 todo；`grep "\[ \]" /path/to/vault/weekly/` 按周检索；`/traft-todos 查 进行中` 筛 `[/]`。
- **约定变更时同步更新本节。**

## 4. 工作流程（WORKFLOW）

### Step 1: 定位周报
- 动作：检查 `weekly/周记 <ISO周>.md` 是否存在（本周）。
- IF 不存在 → 复制 `skills/obsidian/templates/weekly.md` 为 `weekly/周记 <ISO周>.md`，填周期字段，**严格遵循模板格式**。
- 完成标志：周报文件存在，含「📋 本周任务」列表。

### Step 2: 记任务 / 改状态
- IF 新增任务 → 在「📋 本周任务」加一行 `- [checkbox] 优先级 | 内容 | 👤对接人 ⏰时间 | 🔗 [[卡片]]`，字段缺失即省略（优先级必含）。
- IF 状态变更 → 修改对应行的 checkbox 符号：完成 `[x]` / 进行中 `[/]` / 搁置 `[-]` / 下周做 `[>]`。
- IF 周结 → 把本周 `[>]` 的行复制到下周周报列表（结转），`[x]` 留在本周。
- IF 整理/重排 → 按 2.1 规则 7 重排「📋 本周任务」。
- ELSE 非 todo 意图 → 转交 `traft-task` 或默认回复。
- 完成标志：列表内容与用户意图一致，每行符合格式规范，状态符号合法。

### Step 3: 查询 / 汇报
- 动作：按需用 Tasks 过滤语法或 `grep "\[ \]" weekly/` 检索周报，汇总本周 todo。
- 完成标志：给出用户要的 todo 清单（状态、优先级、内容齐全）。

## 5. 输出规范（OUTPUT SPEC）

### 5.1 固定格式
写进周报的一行 todo：

```text
- [ ] 🟡 P1 | 临时任务描述 | 👤 对接人 ⏰ 待定 | 🔗 [[卡片]]
```

状态符号（Tasks 插件，不自由发挥）：

| 符号 | 状态 | 说明 |
|------|------|------|
| `[ ]` | 待办 | 没动手（默认） |
| `[x]` | 完成 | 勾掉，终态 |
| `[/]` | 进行中 | 正在做 |
| `[-]` | 取消/搁置 | 缺依赖停摆 / 已放弃 |
| `[>]` | 转发下周 | 未完成→下周计划 |
| `[<]` | 排期 | scheduling，排期中 |

### 5.2 字段要求

| 段 | 取值 | 写作要求 |
|----|------|------|
| `checkbox` | 见 5.1 状态表 | 勾掉=`[x]`，只用合法符号 |
| `优先级` | 🔥 P0 / 🟡 P1 / 🟢 P2 | 必含，与内容用 `|` 分隔；定义见 3. 知识底座 |
| `内容` | 一句话 | 任务描述，可验收；不臆造 |
| `对接人` | 👤/🧑‍💼/🦊 + 名字 | 可选，无则省略 |
| `deadline` | ⏰ 待定 / 2026-09-11 | 可选，无则省略；相对时间（"周五前"）换算为具体日期 `YYYY-MM-DD`，不写"待定" |
| `卡片` | 🔗 [[xxx]] | 可选，关联需求/文档 |

### 5.3 交付前自检
- [ ] 每行是一个 todo，格式 `- [checkbox] 优先级 | 内容 | …` 完整合规
- [ ] 状态用了合法 Tasks 符号，checkbox 即状态、正文无重复描述
- [ ] 任务写进了周报「📋 本周任务」单一列表，未分块
- [ ] 排序符合 2.1 规则 7
- [ ] 项目需求进展（✨/🐛/🔍）未误记为主体的 todo，已归 `traft-task`

## 6. 示例

### 6.1 好的示例
**输入**：加个todo：周五前把周报数据整理给小明
**输出**：
```text
- [ ] 🟡 P1 | 整理周报内容，交给小明 | 👤 小明 ⏰ 2026-09-11
```
（内容是一句话动作；相对时间"周五"换算为具体日期 `2026-09-11` 写入 deadline；字段齐全、优先级必含）

**输入**：这个 todo 做完了，勾掉
**输出**：对应行 `[ ]` 改为 `[x]`，其余字段不变。

**输入**：整理下周报，重新排个序
**输出**：
```text
- [ ] 🔥 P0 | 给客户出方案 | ⏰ 2026-09-10
- [ ] 🟡 P1 | 整理周报内容，交给小明 | 👤 小明 ⏰ 2026-09-11
- [ ] 🟢 P2 | 补技术文章阅读笔记
- [x] 🔥 P0 | 修复线上告警 | ✅ 2026-09-09
- [x] 🟡 P1 | 同步季度 OKR 到文档
```
（未完成在前、已完成在后；组内 P0 > P1 > P2）

### 6.2 差的示例
**输入**：加个todo：周五前把周报数据整理给小明
**输出**：
```text
- [ ] 周五前把周报数据整理给小明
```
（缺优先级字段；相对时间"周五前"未换算为具体日期，deadline 不成立，不满足格式规范）

**输入**：这个 todo 做完了，勾掉
**输出**：
```text
- [x] 🟡 P1 | 周五前把周报数据整理给小明 | 已完成
```
（正文重复写"已完成"，checkbox 即状态；字段位置错乱）
