# 周级 todo（Tasks 插件 checkbox）

轻量临时小任务，用 Obsidian **Tasks 插件**的 checkbox 管理。**勾掉即完成**。区别于 `traft-task` 管项目任务/需求进展：todo 只管临时小任务，不影响项目进度。

## 一条 todo 的格式

写进周报（或任意笔记）的一行：

```
- [ ] 🟡 P1 | 临时任务描述 | 👤 对接人 ⏰ 待定 | 🔗 [[卡片]]
```

| 段 | 取值 | 说明 |
|----|------|------|
| `checkbox` | `[ ]` `[x]` `[/]` `[-]` `[>]` | 状态符号，勾掉=`[x]` |
| `优先级` | 🔥 P0 / 🟡 P1 / 🟢 P2 | 必含 |
| `内容` | 一句话 | 任务描述（可验收） |
| `对接人` | 👤/🧑‍💼/🦊 + 名字 | 可选 |
| `deadline` | ⏰ 待定 / 08-25 | 可选 |
| `卡片` | 🔗 [[xxx]] | 可选，关联需求/文档 |

> `优先级` 与 `内容` 用 `|` 分隔；对接人/时间/卡片均可选，无则省略。一行 = 一个 todo。

## 任务状态（Tasks 符号，不自由发挥）

| 符号 | 状态 | 说明 |
|------|------|------|
| `[ ]` | 待办 | 没动手（默认） |
| `[x]` | 完成 | 勾掉，终态 |
| `[/]` | 进行中 | 正在做 |
| `[-]` | 取消/搁置 | 缺依赖停摆 / 已放弃 |
| `[>]` | 转发下周 | 未完成→下周计划 |

> 只允许这 5 个符号（对照 `resource/Tasks状态速查表.md`）。正文不重复写"已完成/未开始"，checkbox 即状态。
> todo 只管临时小任务；项目需求进展（✨feat/🐛bugfix/🔍debug）归 `traft-task`。

## 维护任务列表（单一列表）

周报就是**一个 task 列表**，Tasks 插件勾选即状态，不按完成/下周/阻塞分块：

1. **建周报**：复制 `templates/weekly.md` 到 `weekly/周记 <ISO周>.md`，填周期。
2. **加任务**：往「📋 本周任务」列表加 todo，每行一条 `- [checkbox] 优先级 | 内容 | …`。
3. **勾状态**：完成了勾 `[x]`；进行中改 `[/]`；搁置改 `[-]`；下周做改 `[>]`。勾掉即完成，无需挪区块。
4. **周结**：把 `[>]` 的任务复制到下周周报的列表（结转），`[x]` 留在本周即可。
5. 项目/论文/技术进展（✨/🐛/🔍/📖）也作为任务行记进同一列表，但主体归 `traft-task`。

## 与 traft-task 的分工

| | `traft-task` | `traft-todos` |
|---|---|---|
| 管什么 | 项目任务、需求进展（✨feat/🐛bugfix/🔍debug） | 临时小任务 |
| 载体 | `project/…/任务.md` + task-component 视图 | 周报 checkbox 行 |
| 状态 | 待规划/进行中/完成 + task 视图 | Tasks 符号：`[ ]/[x]/[/]/[-]/[>]` |
| 完成 | 项目交付，走评审/发布 | 勾掉 `[x]` 即完 |

- 需要跨周跟进、看板/甘特视图的项目任务 → `traft-task`。
- 随手记、周内临时小活、跟周报走的 → `traft-todos`。
- 项目任务周内完成，可在周报留一条 `[x]` 记录，但主体归 `traft-task`。

## 查询
- Tasks 插件自带查询：`filter by function task.tags.includes('#todo')` 汇总所有 todo。
- `ob-query` 按周检索周报读「本周 todo」；`/traft-todos 查 进行中` 筛 `[/]`。
