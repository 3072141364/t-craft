# traft技能组指南
traft(全称t-craft),是一套自用的工程技能体系，涉及vibe coding、知识库管理(obsidian)、研究调研等场景的技能集合。


```
项目开发、管理(vibe coding) ─┐
                          ├─→ 周报三流(开发/论文/技术)
研究、调研(paper&&research)─┘

知识库
```

## 开发线
| 技能 | 定位 | 触发场景 |
|------|------|----------|
| `traft-git-flow` | git管理规范 |分支创建、commit信息、代码拉取、提交、版本管理、changelog |
| `traft-code-review` | 代码评审规范 |影响面评估、代码评审|
| `traft-graph` | 图表绘制 | 技术图(架构/流程/泳道/UML/C4)绘制 |
