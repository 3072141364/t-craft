# 😀 emoji 速查表

> vault 常用 emoji 对照。**emoji 不进 Obsidian 标签本身**(标签不含 emoji),只作标题/章节/本表的视觉对照。写笔记时 card_type 图标、章节 emoji 向 **emoji-helper** 查询;本表为常用集,emoji-helper 可覆盖。

## card_type 图标(每张卡标题行首)

| card_type | emoji | 用途 |
|-----------|-------|------|
| 方案 | 📋 | 设计方案(开发新功能/修复 bug) |
| 技术 | 🔧 | 技术知识/实践沉淀 |
| 流程 | 📝 | 规范操作记录(可照着执行) |
| 术语 | 📖 | 通用概念定义 |
| wiki | 📚 | 知识词条(科普性解释) |
| 周记 | 📅 | 周报 |

## 周报字段 emoji

### 优先级

| emoji | 取值 | 含义 |
|-------|------|------|
| 🔥 | `🔥 P0 高` | 高优 |
| 🟡 | `🟡 P1 中` | 中优 |
| 🟢 | `🟢 P2 低` | 低优 |

### 类型(工作性质)

| emoji | 取值 | 含义 |
|-------|------|------|
| ✨ | ✨ feat | 新需求 |
| 🐛 | 🐛 bugfix | 修复 |
| 🔍 | 🔍 debug | 排查 |
| 📌 | 📌 临时任务 | 临时任务 |
| 🚀 | 🚀 上线/部署 | 上线动作 |
| 🧪 | 🧪 测试验证 | 验证 |
| 🧠 | 🧠 方案深挖 | 深度思考 |
| 📥 | 📥 等待输入 | 待数据/待对接 |

### 状态

> 周报状态用 Tasks 扩展符号(见 [[Tasks 状态速查表]]),**不用 emoji**。本节仅列章节/行内标注可选的 emoji。

| emoji | 含义 |
|-------|------|
| ✅ | 完成(行内标注备用,主状态用 `[x]`) |
| ⬜ | 未开始(行内标注备用,主状态用 `[ ]`) |

## 章节语义 emoji(正文章节标题可选)

| emoji | 语义 |
|-------|------|
| 🐛 | 现象/问题 |
| 🔍 | 定位 |
| ✅ | 处理/结论 |
| ❓ | 待确认 |
| 🔗 | 关联 |
| 📌 | 临时/备注 |
| 🚧 | 阻塞/进行中 |
| 📥 | 沉淀/输入 |

## 人名 emoji

> 出现人名时加**身份 emoji** 前缀(紧贴名字),让人一眼分辨是人名且知身份。身份 emoji 对照见 [[people]]。

| emoji | 身份 | 示例 |
|-------|------|------|
| 👤 | 其他同事(默认) | `👤张三` |
| 🧑‍💻 | 组内同事 | `🧑‍💻李四` |
| 🦊 | 我 | `🦊卫泽恩` |
| 🧑‍💼 | 负责人 | `🧑‍💼白立建` |
| 🤝 | 外部协作 | `🤝王五` |
| 🧑‍🏫 | mentor | `🧑‍🏫赵六` |
| 👥 | 团队 | `👥感知组` |

> 默认用 `👤`;组内用 `🧑‍💻`;对接的关键人用 `🧑‍💼`;人名先登记到 [[people]] 花名册。
