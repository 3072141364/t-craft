## 周报字段 emoji

### 优先级

| emoji | 取值 | 含义 |
|-------|------|------|
| 🔥 | `🔥 P0 高` | 高优 |
| 🟡 | `🟡 P1 中` | 中优 |
| 🟢 | `🟢 P2 低` | 低优 |

### 类型(工作性质)

| emoji | 取值 | 含义 |
|-------|------|------|
| ✨ | ✨ feat | 新需求 |
| 🐛 | 🐛 bugfix | 修复 |
| 🔍 | 🔍 debug | 排查 |
| 📌 | 📌 临时任务 | 临时任务 |
| 🚀 | 🚀 上线/部署 | 上线动作 |
| 🧪 | 🧪 测试验证 | 验证 |
| 🧠 | 🧠 方案深挖 | 深度思考 |
| 📥 | 📥 等待输入 | 待数据/待对接 |

### 状态

> 周报状态用 Tasks 扩展符号(见 [[Tasks 状态速查表]]),**不用 emoji**。本节仅列章节/行内标注可选的 emoji。

| emoji | 含义 |
|-------|------|
| ✅ | 完成(行内标注备用,主状态用 `[x]`) |
| ⬜ | 未开始(行内标注备用,主状态用 `[ ]`) |

## 人名 emoji

> 出现人名时加**身份 emoji** 前缀(紧贴名字),让人一眼分辨是人名且知身份。身份 emoji 对照见 [[people]]。

| emoji | 身份 | 示例 |
|-------|------|------|
| 👤 | 其他同事(默认) | `👤张三` |
| 🧑‍💻 | 组内同事 | `🧑‍💻李四` |
| 🦊 | 我 | `🦊卫泽恩` |
| 🧑‍💼 | 负责人 | `🧑‍💼白立建` |
| 🤝 | 外部协作 | `🤝王五` |
| 🧑‍🏫 | mentor | `🧑‍🏫赵六` |
| 👥 | 团队 | `👥感知组` |

> 默认用 `👤`;组内用 `🧑‍💻`;对接的关键人用 `🧑‍💼`;人名先登记到 [[people]] 花名册。

## CHANGELOG 分类

> 对应 [Keep a Changelog](https://keepachangelog.com/) 分类,可在 CHANGELOG 条目前加 emoji 增强可读性。

| Emoji | 类别 | 含义 |
|------|------|------|
| ✨ / 🆕 | Added | 新增功能 |
| 🔧 / 🔄 | Changed | 对已有功能的变更 |
| 🗑️ / ⚠️ | Deprecated | 即将移除 |
| ❌ / 🔥 | Removed | 本版本移除 |
| 🐛 / 🩹 | Fixed | 缺陷修复 |
| 🔒️ / 🛡️ | Security | 安全相关修复 |

## 备注

- emoji 在不同字体/平台渲染略有差异,核心语义一致。
- 终端使用需确认终端支持 emoji 渲染(现代终端均支持)。
- commit message 中 emoji 建议放行首,遵循 gitmoji 约定。
- 过度使用 emoji 可能影响可读性,建议每行不超过 1-2 个,关键信息优先用文字表达。
