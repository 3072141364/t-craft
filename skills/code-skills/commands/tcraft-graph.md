通过 Skill 工具正式调用 **fireworks-tech-graph** 绘制技术图。方法论(布局、对称、箭头接边、副说明、语义配色、留白、验证、视觉复检)以该 skill 的 SKILL.md 和 references/ 为准,本命令不复述,只叠加下面几条偏好。

## 参数

- 无参数:对当前对话里已讨论清楚的结构/流程画图(若还不清楚画什么,先问用户)。
- `<一句话描述>`(如 `/tcraft-graph 画 RAG 检索链路`):按描述画。

## 执行

1. 用 Skill 工具调用 `fireworks-tech-graph`,走它的完整 workflow。风格默认 Style 1(Flat Icon),除非用户指定。
2. **默认只产出 SVG**(矢量、浏览器直接打开)。**仅当用户明确要 PNG/位图时**才导出 PNG。
3. 生成后按 skill 的要求做验证 + 视觉复检(能读图就把图读回来目检),最多两轮修正。

## 偏好(叠加在 skill 之上)

- **逻辑清晰 + 设计感兼得**:两者都要,不接受"逻辑对但难看"或"好看但看不懂"。skill 的布局/配色规范已支持,照它做即可。
- **参考已有图时先问方向**:用户拿一张已有图当参照(要求"像这张"或"融合这两张")时,先确认以逻辑还是设计为主、以哪张为基,再画。
- **环境相关的处理**(渲染器、字体、脚本兼容等)按当前环境走;若个人记忆里有相关经验,优先采用记忆里的做法——这些不写死在本命令里。
