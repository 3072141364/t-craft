# 周报规则(weekly)

> obsidian-kb 的附属文档:周报怎么写。建周报 / 写周记 / 复盘本周时读本文。

## 定位:周报记「事情」,需求进度归 progress.md

**周报记录本周干了什么**(开发 / 论文 / 技术三条工作流),是事情流水 + 沉淀指针,不是需求状态簿。

- 具体需求的进度(状态、阶段、下一步)在对应需求的 `progress.md`——那是**状态真源**,接 dev-flow 六阶段。
- 周报里提到某需求时,只链到它的 progress.md(`[[projects/<名>/requirements/<需求名>/progress]]`),**不复制、不重复维护状态**。状态变了改 progress.md,周报自动反映(cards.base「进行中需求」视图)。
- 判断标准:写周报时这句是"我做了 X 事" → 记周报;是"需求 Y 现在到哪个阶段了" → 更新 Y 的 progress.md。

## 文件位置

- `weekly/周记 <YYYY>-W<ww>.md`(周次用 ISO week,如 `周记 2026-W32.md`)
- 周次换算:周一日期所在年的第几周;Python `date.isocalendar()` 可得。
- 模板在 skill 仓库 `obsidian-kb/assets/templates/weekly.md`。

## 章节结构(三流 + 通用四节)

```
## 📌 本周开发(projects)   <- 项目上的事,带子项
## 📖 本周论文(papers)      <- 读的论文(链 [[papers/xxx]],阅读走 research-skills 的 paper-study)
## 🔧 本周技术(tech)        <- 学的技术(链 [[tech/xxx]])
## 🚧 问题 / 阻塞           <- 卡住的 + 风险
## 📥 沉淀                  <- 本周新增/关联卡片(可复用知识已提炼进 skill 仓库?)
## 📅 下周计划
```

## todo 项格式

每项一行,字段用 `|` 分隔,顺序固定:

```
- [checkbox] 优先级 类型 | 内容 | 👤对接人 ⏰时间 | 🔗 [[卡片]]
```

| 字段 | emoji | 取值 | 说明 |
|------|-------|------|------|
| checkbox | — | 见「状态符号」 | Tasks 插件扩展符号 |
| 优先级 | 🔥/🟡/🟢 | `🔥 P0 高` `🟡 P1 中` `🟢 P2 低` | emoji + 级别 + 文字都保留 |
| 类型 | ✨/🐛/🔍/📌 | ✨ feat · 🐛 bugfix · 🔍 debug · 📌 临时任务 | 工作性质分类 |
| 内容 | — | 一句话 | 简洁,带 commit 号 / 关键标识 |
| 对接人 | 👤 | 姓名 | 协作关键人 |
| 预期时间 | ⏰ | `MM-DD` 或 `待定`/`待数据` | deadline |
| 关联卡片 | 🔗 | `[[卡片名]]` | vault 跳转,无关联省略 |

## 状态符号(Tasks 插件扩展)

依赖 Obsidian Tasks + Minimal 主题渲染 checkbox 扩展符号。**仅允许以下两类,不得越界使用其余符号**(如 `[w]`/`[!]`/`[*]` 等标记/信息/评价类):

| 符号 | 语义 | 用途 |
|------|------|------|
| `[ ]` | 待办 TODO | 未开始 |
| `[x]` | 完成 DONE | 已完成 |
| `[/]` | 进行中 IN_PROGRESS | 正在推进 |
| `[-]` | 取消 CANCELLED | 搁置/取消(含缺依赖停摆) |
| `[>]` | 转发 forwarded | 转到下周/下阶段 |
| `[<]` | 排期 scheduling | 定稿排期、待到时 |

- **checkbox 即状态**:符号本身表达进度,正文不重复写"已完成/未开始"。
- **搁置用 `[-]` 不用 emoji**:不用 ⏸️ 行内标注;缺依赖停摆一律 `[-]`。
- **进行中用 `[/]` 不用 emoji**:不用 🔄 行内标注。
- **父子项关系**:父项描述一件事,子项是拆出来的具体步骤。**所有子项都完成,父项才能标 `[x]`;否则父项保持 `[/]`**。
- **子项继承父项**:对接人 / 卡片默认继承父项,仅不同时才写;子项用 tab 缩进表从属。
- **事项排序**:未完成在前、高优在前;已完成排后、搁置排未完成之后。顺序:未完成 P0 > 未完成 P1 > 搁置 > 已完成。

## 工作流

1. **本周第一个工作日**:建当周周记卡(复制模板 `obsidian-kb/assets/templates/weekly.md`),先列下周计划。
2. **每做完一件事**:先落产出——需求 → 更新对应 `progress.md` 状态;论文 → `papers/`;技术 → `tech/` 或提炼进 skill 仓库——再在周报加 todo 项 / 沉淀指针。**产出先归位,周报只加指针。**
3. **下周初**:未完成项移入下周计划;本周归档(移 `archive/` 或保留,按项目约定)。

## emoji 联动

类型/优先级 emoji 不在本 skill 硬编码,默认集(✨🐛🔍📌 / 🔥🟡🟢)在周记模板图例;状态不用 emoji 用扩展符号。新增字段 emoji 向 obsidian-kb 附属文档 emoji-helper.md 查询。

## 人名 emoji

文档/卡片/周报里出现**人名**时,加身份 emoji 前缀(emoji 紧贴名字)。身份对照与花名册见 [[people]]。提到的人先登记到花名册(同一人中英文名用 aliases 关联)再在正文用对应 emoji。
