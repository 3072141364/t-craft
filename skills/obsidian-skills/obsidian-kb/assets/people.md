# 👥 人员

> vault 涉及的人员花名册。同一人的中英文名用 `aliases` 关联,避免当成两个人;身份用不同 emoji 标识,文档里提到该人时用对应 emoji 作前缀(见 [[emoji-cheatsheet#人名 emoji]])。
> 本卡随工作推进逐条维护,不强求一次建全。

## 身份 emoji 对照

| emoji | 身份 | 含义 |
|-------|------|------|
| 👤 | 其他同事 | 默认,内部成员但不属本组 |
| 🧑‍💻 | 组内同事 | 同组/同项目成员 |
| 🦊 | 我 | 自己 |
| 🧑‍💼 | 负责人 | owner,事项对接的关键人 |
| 🤝 | 外部协作 | 跨团队/外部供应商 |
| 🧑‍🏫 | mentor | 指导者 |
| 👥 | 团队 | 指一组人而非个人 |
