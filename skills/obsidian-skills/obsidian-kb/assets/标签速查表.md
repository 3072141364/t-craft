# 🏷️ 标签速查表

> vault 标签约定。标签小写 + 连字符,层级用 `/`。**emoji 不进标签本身**(Obsidian 标签不含 emoji),只作标题/章节/本表的视觉对照。写笔记时 card_type 图标 emoji 向 **emoji-helper** 查询,本表为常用对照,emoji-helper 可覆盖。

## 项目标签

| 标签 | emoji | 含义 | 何时用 |
|------|------|------|--------|
| `项目/<名>` | 📁 | 归属项目 | 卡片/方案属某项目时打 |

## 类型标签(对应 card_type)

| 标签 | emoji | card_type | 何时用 |
|------|------|-----------|--------|
| `类型/方案` | 📋 | 方案 | 设计方案 |
| `类型/升级` | 🚀 | 升级 | 升级/迁移文档 |
| `类型/问题修复` | 🐛 | 问题修复 | bug 完整修复 |
| `类型/会议` | 👥 | 会议 | 会议记录 |
| `类型/周记` | 📅 | 周记 | 周报 |
| `类型/日记` | 📝 | 日记 | daily note |
| `类型/术语` | 📖 | 术语 | 通用概念定义 |
| `类型/决策` | ⚖️ | 决策 | 选型/取舍 + 理由 |
| `类型/踩坑` | 🪤 | 踩坑 | 错误 + 根因 + 解法 |
| `类型/模式` | 🧩 | 模式 | 可复用做法 |
| `类型/事实` | 💡 | 事实 | 不显然的系统约束 |

## 主题标签(示例,按需扩展)

`通用/AI`、`通用/工具`、`通用/规范`、`通用/环境` —— 与 `通用/` 文件夹主题对应。

## 用法

- 优先 frontmatter `tags:` 列表,正文确有需要再 inline `#tag`。
- 一卡 2-5 个,不滥用,关联性强才打。
- **新标签先加到此表再用**,避免同义分裂(`#bug` vs `#缺陷`)。
- emoji 选择以 **emoji-helper** 查询为准,本表为常用对照。
