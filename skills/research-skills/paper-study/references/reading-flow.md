# 阅读工作流(reading-flow)

> paper-study 的附属文档:论文从收集到读完的流程与状态流转。收论文 / 读论文 / 整理阅读清单时读本文。

## 四步流转

```
待读(reading-list)→ 粗读(判价值)→ 精读(记笔记)→ 已读(可复用)
```

| 阶段 | 动作 | 落点 |
|------|------|------|
| 待读 | 看到值得读的论文,先记进队列,不打断当前阅读 | `papers/reading-list.md` |
| 粗读 | 读 abstract / 结论,判值不值得精读 | 值 → 建论文卡,状态「在读」;不值 → 在队列标"略读/不读" |
| 精读 | 读全文,记笔记(见 note.md) | 论文卡状态「在读」→「已读」 |
| 已读 | 提炼可复用思路,接到项目 / 技术 / 周报 | 论文卡 + `tech/` / `projects/<名>` / 周报 |

## 待读队列(reading-list.md)

`papers/reading-list.md` 是队列真源,模板在 skill 仓库 `assets/templates/reading-list.md`。

- 每条一行:论文名 + 来源(链接/DOI)+ 主题标签 + 优先级(🔥 高 / 🟡 中 / 🟢 低)。
- **收论文优先记队列**,不要中途开精读——保持当前阅读不被打断。
- 粗读后:值得精读 → 建卡 + 从队列移除;不值得 → 标"略读"留档或删除。

## 状态流转

论文卡 frontmatter `status`:`待读`(在队列/已建卡未读)→ `在读`(粗读通过,精读中)→ `已读`(笔记完成)。

- **已读判据**:note.md 的四节都填了(为什么读/核心/关联/批判),不是"看完了"。
- 读完但没记笔记 → 不算已读,保持「在读」。

## 批量整理

用户要"整理阅读清单""这周读了哪些论文"时:

- 按 `reading-list.md` 状态 / 主题列出队列。
- 按周报「本周论文」节的链接汇总本周已读。

## 与周报联动

每周在周报「📖 本周论文(papers)」节列本周读的论文(链 `[[papers/<论文名>]]`),读书的进展记队列/论文卡状态,周报只加指针。
