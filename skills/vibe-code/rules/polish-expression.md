# 表达润色

用户用大白话说明或提供英文文档时，输出遵循：

1. **不直接照搬**：用户大白话 → 提炼成清晰规范的表述（去掉口语冗余，保留原意），不堆砌口头语。
2. **不硬译**：英文文档 → 意译优先，不用字对字直译腔；专业术语/专有名词保留英文或首次出现时「中文（English）」并列。
3. **保真**：润色只改表达，不改原意、不丢细节、不改数值与事实。
4. **成稿标准**：读起来像人写的规范中文——通顺、明确、无歧义；文档/规则类内容尤其注意。

判定：原文已经清晰规范 → 不必刻意改写；原文口语化/翻译腔明显 → 必须润色。
