触发 `traft-requirements` skill 的需求深挖流程(研发流程阶段①)。

## 参数
- 无参数:对当前对话中已提到的需求深挖;若对话里还没有明确需求,先问用户"要深挖什么"。
- `<一句话需求描述>`(如 `/tcraft-brainstorm 给导出加 PDF 格式`):对该需求深挖。

## 执行
读 `skill://traft-requirements`,按其流程走:

1. 探索上下文先(读相关代码/文档/项目上下文,用 traft-obsidian 查本项目既有需求)。
2. 画设计树(真实意图->约束->边界->风险->验收标准->旧方案)。
3. 前沿轮次追问(一轮一批、逐条编号、附推荐答案;事实自查、决策问人)。
4. 按需上追问工具(5-Whys / first-principles)。
5. 产出需求要点(对话内按模板呈现)**用户确认后才交接**。
6. 交接阶段②(traft-code-docs 落 prd,progress 状态推进)。

不写代码、不落方案文件;用户确认前不进实现。
