# traft-code-review 代码评估审查

对一段改动做双轴审查:**Standards 轴**(代码本身对不对:异味、行为准则、项目规范)与 **Spec 轴**(改动达没达成需求:对照 prd 验收标准)。两档深度:**影响面评估**(轻量,扫 diff + 波及范围)与**全量评估**(双轴完整走,研发阶段④)。只出报告不改码;代码查证(调用链 / 影响面)按 traft-code-intelligence 路由走。

## RULES

### ALWAYS DO
- **双轴都要看**:只审 Standards 漏掉需求达成,只核 Spec 漏掉代码质量;每条问题标注所属轴。
- **拿改动用纯 git**：未提交 `git diff`、指定范围 `git diff <base..head>`、历史 `git log -p`;VCS 无关。
- **查证走 traft-code-intelligence**:谁调用 / 影响面 / 执行流按其路由表(gitnexus / LSP / read 工具组),不肉眼硬追。
- **问题带定位**:每条给出文件 + 行号(或 hunk),异味标"可能 X"(判断题,不是硬违规)。
- **结论当先**:报告先给可发布 / 需修,再列问题清单(轴 / 位置 / 问题 / 建议 / 严重度)。
- **需求达成确认**:Spec 轴对照 prd.md 验收标准逐条核对成表;回归影响对照 prd「AI 须知的变更清单」预判 vs 实际。

### NEVER DO
- 不改代码、不代修复;只出报告与建议。
- 不审格式(空格 / 缩进 / 行长)--交 lint / `make format`,报告里不列。
- 不凭印象断言调用关系--用工具查证,有证据才写。
- 不把启发式异味当硬违规:项目规范明确认可的压下不报;linter / 类型检查能查的跳过。

## 审查流程

1. **定档定范围**:影响面评估(轻量)= Standards 轴扫 diff + 波及范围;全量评估(默认)= 双轴完整 + 需求达成确认 + 回归影响,研发阶段④必走全量。范围用 git 确定。
2. **Standards 轴**:对照下方异味基线逐味扫 diff,标"可能 X"引对应 hunk;再查外科手术式修改--每行改动能否直接追溯到需求,有没有顺手改无关代码 / 删无关死代码。
3. **Spec 轴**:读对应需求的 prd.md(traft-code-docs 的 `requirements/<需求名>/`),验收标准逐条核对,产出达成确认表;没有 prd 时向用户确认需求要点后再核。
4. **回归影响**:影响面走 traft-code-intelligence(`gitnexus-impact-analysis`,要结论别用快瞥);对照 prd「AI 须知的变更清单」预判 vs 实际。
5. **出报告**:对话内呈现,结论当先;要落盘时按 traft-code-docs 的 `templates/review.md` 走审批写入 `requirements/<需求名>/review.md`。
6. **交接**:可发布 -> 提交走 traft-code-git;需修 -> 列未完成项交回修改,修完重审。

## Standards 轴基线(12 味,匹配 diff 标"可能 X")

| 异味 | 一句话判据 | 修法 |
|------|-----------|------|
| 神秘命名 | 名字看不出做什么 / 装什么 | 改名;取不出诚实名字 = 设计浑浊 |
| 重复代码 | 同一逻辑形状在改动里多处出现 | 抽共享形状,两处都调它 |
| 依恋情结 | 方法更多伸手到别的对象的数据 | 把方法搬到它羡慕的数据上 |
| 数据泥团 | 同几个字段 / 参数总一起出现 | 捆成一个类型,传它 |
| 基本类型偏执 | 用基本类型顶替该有类型的领域概念 | 给概念一个小类型 |
| 重复 switch | 对同一类型的 switch / if 链反复出现 | 多态替换,或两处共用一个 map |
| 霰弹式修改 | 一个逻辑改动在多文件散改 | 一起变的收进一个模块 |
| 发散式修改 | 一个模块因多种不相关原因被改 | 拆成每个模块只为一个原因变 |
| 投机性泛化 | 为 spec 没有的需求加抽象 / 参数 / hook | 删掉,内联回去直到真有需求 |
| 消息链 | 长 `a.b().c().d()` 导航 | 在第一个对象背后藏一个方法 |
| 中间人 | 类 / 函数几乎只转发 | 砍掉,直接调真目标 |
| 被拒继承 | 子类忽略 / 覆盖大部分继承来的东西 | 弃继承,用组合 |
- 每味是判断题不是硬违规;项目规范明确认可的做法压下不报。
- linter / 类型检查能查的跳过(格式、命名交工具)。
